# FoosDB 接口调用说明

> 本文档面向前端（admin-vue）开发，覆盖 FoosDB 后端所有 HTTP API。
> 端口 `8858`，统一返回格式 `{ data, error? }` 或 `{ ok: true, ... }`。

---

## 1. 基础约定

### 1.1 Base URL & 代理

```
本地开发:  http://localhost:8858
Vite 代理: /api  → http://localhost:8858/api
```

### 1.2 通用请求头

| Header                           | 必填                  | 说明                                                             |
| -------------------------------- | --------------------- | ---------------------------------------------------------------- |
| `Authorization: Bearer <token>`  | 视接口而定            | 登录后拿到的 `access_token`                                      |
| `Content-Type: application/json` | POST/PUT/PATCH/DELETE | 请求体为 JSON                                                    |
| `X-Client-Id`                    | 推荐                  | 客户端指纹，每次登录/调用同一设备保持不变（如浏览器用固定 UUID） |
| `User-Agent`                     | 自动                  | 后端用 UA 计算指纹（当 X-Client-Id 缺失时）                      |

### 1.3 客户端指纹（JWT 安全机制）

后端对**每次请求**计算指纹并与 JWT 里签发时的指纹比对。计算规则：

- 有 `X-Client-Id` 头 → `sha256("cid:" + clientId)`
- 无 `X-Client-Id`，有 `User-Agent` → `sha256("ua:" + userAgent)`
- 都没有 → `"unknown"`（不推荐）

**同一 JWT 只能在同一指纹设备上使用**——跨设备复用会被拒（防止 token 被盗用）。

前端实现：

```ts
// 第一次进入时生成并持久化
let clientId = localStorage.getItem("x-client-id");
if (!clientId) {
  clientId = crypto.randomUUID();
  localStorage.setItem("x-client-id", clientId);
}
// 每次请求带上
headers["X-Client-Id"] = clientId;
```

### 1.4 错误响应

所有错误统一格式（4xx/5xx）：

```json
{ "error": "english message | 中文消息" }
```

**消息格式约定**：后端从现在起返回双语消息，格式为 `English | 中文`（英文在前，`|` 分隔，无额外空格/引号）。前端可以按需提取：

```ts
/** 从后端双语错误消息中提取适合显示的版本。
 *  - 有中文（| 分隔）→ 返回中文
 *  - 只有英文（旧格式或后端临时返回英文）→ 返回英文
 *  - 空/null → 返回通用兜底
 */
export function extractCn(msg?: string | null, fallback = "请求失败"): string {
  if (!msg) return fallback;
  const idx = msg.indexOf("|");
  if (idx === -1) return msg.trim(); // 只有英文或其他格式，原样返回
  return msg.slice(idx + 1).trim() || fallback; // 取 | 之后的中文
}

// 拦截器里用：
(err.response?.data?.error ?? err.message).split("|").pop()?.trim() ??
  "请求失败";
```

常见状态码：

| 码  | 场景                                                  |
| --- | ----------------------------------------------------- |
| 400 | 参数格式错误                                          |
| 401 | token 缺失/过期/签名不对/指纹不匹配                   |
| 403 | 无权限（需要 admin-panel scope 或 object 绑定不匹配） |
| 404 | 资源不存在                                            |
| 409 | 用户名/项目名重复                                     |
| 429 | 登录限流（响应头含 Retry-After）                      |
| 500 | 服务端内部错误                                        |

## 2. 认证接口 `/api/auth/*`

### 2.1 POST `/api/auth/login` — 登录

```json
// 请求
{ "username": "admin", "password": "admin123" }
```

```json
// 响应（成功）
{
  "data": {
    "expires": 1788440070,
    "refresh_expires": 1788443670,
    "access_token": "eyJhbGciOi...（JWT 三段）",
    "refresh_token": "eyJhbGciOi...（JWT 三段）",
    "token_type": "Bearer"
  }
}
```

**JWT payload 字段**（base64 解码后）：

| 字段        | admin-panel                 | 业务用户                 |
| ----------- | --------------------------- | ------------------------ |
| `sub`       | 真实 users.id（如 1）       | 真实 users.id（如 2）    |
| `username`  | 匹配 .env 的 ADMIN_USERNAME | users 表值               |
| `nickname`  | "超级管理员(shadow)"        | users 表值               |
| `object_id` | `-1`（系统管理员）          | 绑定的项目 id            |
| `tv`        | token_version（动态）       | token_version（动态）    |
| `fp`        | 指纹（sha256）              | 指纹（sha256）           |
| `scope`     | **`"admin-panel"`**         | **不存在**               |
| `type`      | `"access"` / `"refresh"`    | `"access"` / `"refresh"` |

**响应头**：

- `X-RateLimit-Limit: 5` — 限流阈值
- `X-RateLimit-Remaining: 4` — 剩余次数

**403 特殊场景**：密码对，但 `users.object_id = 0` → `"用户未配置项目信息，请联系管理员分配项目后再登录"`

**429 限流响应**：

```json
{
  "error": "TOO_MANY_REQUESTS",
  "message": "登录尝试过于频繁，请 55 秒后重试。",
  "retryAfterSec": 55
}
```

头：`Retry-After: 55`

### 2.2 GET `/api/auth/me` — 验证当前 token

**需要 Bearer token。**

```json
{
  "data": {
    "id": 1,
    "username": "admin",
    "nickname": "超级管理员(shadow)",
    "token_type": "access",
    "token_version": 49,
    "object_id": -1,
    "expires": 1788440070
  }
}
```

### 2.3 POST `/api/auth/refresh` — 刷新 access_token

```json
// 请求
{ "refresh_token": "eyJhbGciOi..." }
```

```json
// 响应（与 login 返回结构相同）
{
  "data": {
    "expires": ..., "refresh_expires": ...,
    "access_token": "...", "refresh_token": "...",
    "token_type": "Bearer"
  }
}
```

**安全机制**：refresh 会作废上一代 token（单-use），同一 refresh 被二次使用会触发 family 级失效 → 强制重新登录。

### 2.4 POST `/api/auth/logout` — 登出

```json
// 请求（refresh_token 可选；没传就只清 access_token 客户端侧）
{ "refresh_token": "eyJhbGciOi..." }
```

```json
// 响应
{ "revoked": 1 }
```


### 3.5 POST `/api/admin/db/update` — 更新行

**必须提供 WHERE**（防误全表更新）。

```json
// 请求
{
  "table": "users",
  "data": { "object_id": 2 },
  "where": "id = ? AND object_id = ?",
  "whereParams": [5, 1]
}
```

```json
// 响应
{ "ok": true, "table": "users", "changes": 1 }
```

### 3.6 POST `/api/admin/db/delete` — 删除行

**必须提供 WHERE**（防误全表删除）。

```json
{
  "table": "users",
  "where": "username = ?",
  "whereParams": ["temp"]
}
```

```json
{ "ok": true, "table": "users", "changes": 1 }
```

### 3.7 POST `/api/admin/db/refresh-tokens/cleanup` — 手动清理过期 refresh_tokens

```json
{ "ok": true, "removed": 42 }
```

### 3.8 POST `/api/admin/db/checkpoint` — WAL checkpoint（TRUNCATE）

```json
{ "ok": true, "result": [{ "busy": 0, "log": 0, "checkpointed": 251 }] }
```

better-sqlite3 `pragma("wal_checkpoint(TRUNCATE)")` 返回**数组**（唯一元素为 checkpoint 结果）。

- `busy: 0` 表示没有其他连接正在写 WAL；非 0 时 checkpoint 被跳过（WAL 保留）
- `log` 之前 WAL 里的帧数；`checkpointed` 实际合并回主库的帧数
- 只影响 WAL 文件（`app.db-wal` / `app.db-shm`），主库数据零损失

### 3.9 GET `/api/admin/db/meta` — 数据库元信息

```json
{
  "ok": true,
  "journalMode": "wal",
  "tables": 9,
  "rowCounts": {
    "object": 2,
    "users": 5,
    "refresh_tokens": 3,
    "refresh_tokens_expired": 0
  },
  "wal": [{ "busy": 0, "log": 0, "checkpointed": 0 }]
}
```

## 6. 通用业务 CRUD `/api/:object/:table/*`

**鉴权**：取决于 `object.auth_required`。

- `auth_required=0` → 匿名可访问（可选带 token 做绑定校验）
- `auth_required=1` → 必须带 Bearer token

**`object`** 是 app.db.object.name（如 `sqlite_app`）。**`table`** 是数据库里的真实表名（如 `users`、`posts`、`object`）。

### 6.1 GET `/api/:object/:table` — 分页列表

```
GET /api/sqlite_app/posts?page=1&pageSize=20
```

**Query 参数**：

| 参数       | 说明                                                            |
| ---------- | --------------------------------------------------------------- |
| `page`     | 页码，默认 1                                                    |
| `pageSize` | 每页条数，默认 20，最大 5000                                    |
| `__one`    | `"true"` → 按条件查一行（见下方 filter）                        |
| `nopage`   | `"true"` → 不分页，返回完整 data 数组                           |
| `orderBy`  | 排序字段，如 `created_at` 或 `created_at,-id`（多字段逗号分隔） |
| `order`    | `"asc"`                                                         | `"desc"`，需配合 orderBy |
| `fields`   | 仅返回指定字段，逗号分隔，如 `id,username,nickname`             |
| `join`     | JOIN 配置，JSON 字符串（见下）                                  |
| 任意字段名 | 作为 filter，如 `status=published` 或 `id__gte=100`（见下）     |

**响应**：

```json
{
  "data": [ { ... }, { ... } ],
  "total": 662, "page": 1, "pageSize": 20
}
```

**Filter 语法**（Directus 风格）：

| 语法                | 含义        | 示例                    |
| ------------------- | ----------- | ----------------------- |
| `field=value`       | 精确匹配    | `status=published`      |
| `field__eq=v`       | 同上        | 等价                    |
| `field__neq=v`      | 不等于      | `object_id__neq=-1`     |
| `field__lt=v`       | 小于        | `id__lt=10`             |
| `field__lte=v`      | 小于等于    |                         |
| `field__gt=v`       | 大于        | `price__gt=100`         |
| `field__gte=v`      | 大于等于    |                         |
| `field__in=a,b,c`   | 多值 IN     | `id__in=1,2,3`          |
| `field__like=%v%`   | 模糊匹配    | `title__like=%hello%`   |
| `field__null=true`  | IS NULL     | `deleted_at__null=true` |
| `field__null=false` | IS NOT NULL |                         |

**JOIN 语法**（JSON 字符串）：

```
/api/sqlite_app/posts?join={"author":{"on":"users.id=posts.author_id","type":"one"}}
/api/sqlite_app/posts?join={"comments":{"on":"comments.post_id=posts.id","type":"many"}}
```

`type` = `"one"` (LEFT JOIN，返回嵌套对象) | `"many"` (LEFT JOIN，返回嵌套数组)

### 6.2 GET `/api/:object/:table/:id` — 按主键查一行

```
GET /api/sqlite_app/users/2
GET /api/sqlite_app/posts/1001?fields=id,title,author_id&join={"author":{"on":"users.id=posts.author_id","type":"one"}}
```

### 6.3 POST `/api/:object/:table` — 插入行

## 7. 自定义 SQL 执行 `/api/custom/:name`（项目级 auth）

`name` 是 `/api/config/query-templates` 里的模板名。

### POST `/api/custom/:name`

```json
POST /api/custom/get_sales_summary
{ "params": { "since": "2024-01-01" } }
```

**响应**：

```json
{ "ok": true, "rows": [ ... ], "count": 42 }
```

**安全机制**：

- 继承模板绑定的 `object.auth_required` —— 该项目开启认证则必须带 Bearer

- 审计日志自动写入 `custom_query_log`（敏感参数 password/secret/token 自动脱敏）

## 8. 运维接口 `/api/system/*`

### 8.1 POST `/api/system/restart` — 触发优雅重启

**需要 admin-panel scope AND `.env ALLOW_SYSTEM_RESTART=true`**。否则返回 404（隐藏存在）。

```json
POST /api/system/restart
{}
```

```json
{ "ok": true, "message": "进程即将在约 1 秒后优雅退出", "cooldownSec": 30 }
```

**安全机制**：

- 进程内 30 秒防重冷却
- 发 202 后 1 秒才 `process.exit(0)`（确保 HTTP 响应已发送）
- **需要外部守护进程（PM2 / systemd）拉起新实例**；纯 node 进程退出后没人拉 = 服务停

### 8.2 GET `/health` — 健康检查

```json
{ "ok": true, "uptime": 123456 }
```

## 9. 认证状态管理（前端侧）

### 9.1 登录 → Token 存储

```ts
const loginRes = await http.post("/api/auth/login", { username, password });
const token = loginRes.data.access_token;
const refresh = loginRes.data.refresh_token;
// 存 localStorage
localStorage.setItem("access_token", token);
localStorage.setItem("refresh_token", refresh);
```

### 9.2 请求拦截器自动注入

```ts
// 伪代码：每次请求加头
const token = localStorage.getItem("access_token");
if (token) headers["Authorization"] = `Bearer ${token}`;
headers["X-Client-Id"] = localStorage.getItem("x-client-id");
```

### 9.3 Token 过期自动刷新

```ts
// 伪代码：拦截 401，用 refresh_token 换新 access_token
async function handle401() {
  const refresh = localStorage.getItem("refresh_token");
  const r = await http.post("/api/auth/refresh", { refresh_token: refresh });
  localStorage.setItem("access_token", r.data.access_token);
  localStorage.setItem("refresh_token", r.data.refresh_token);
  return r.data.access_token;
}
```

**关键**：refresh 是轮换（单 use），刷新成功后**旧 refresh_token 作废**——必须用返回的新 refresh_token 覆盖本地存储。

### 9.4 登出

```ts
await http.post("/api/auth/logout", {
  refresh_token: localStorage.getItem("refresh_token")
});
localStorage.removeItem("access_token");
localStorage.removeItem("refresh_token");
```

### 9.5 Access Token TTL & Refresh Token TTL

| Token         | 默认   | 可配置                       |
| ------------- | ------ | ---------------------------- |
| access_token  | 2 小时 | `.env ACCESS_TOKEN_TTL_SEC`  |
| refresh_token | 7 天   | `.env REFRESH_TOKEN_TTL_SEC` |

admin-panel 和业务用户的 TTL 相同，无差异。

### 13.1 HTTP 客户端初始化（自动指纹 + Token 注入 + 响应解包）

```ts
import Axios from "axios";
import Cookies from "js-cookie";

// —— 客户端指纹（首次访问生成 UUID，localStorage 持久化）——
const CLIENT_ID_KEY = "x-client-id";
function getClientId(): string {
  let id = localStorage.getItem(CLIENT_ID_KEY);
  if (!id) {
    id = crypto.randomUUID();
    localStorage.setItem(CLIENT_ID_KEY, id);
  }
  return id;
}

export const fastify = Axios.create({
  baseURL: "/api", // Vite 代理到 http://localhost:8858
  timeout: 15000,
  headers: { "Content-Type": "application/json", Accept: "application/json" }
});

// 请求拦截：自动加 X-Client-Id 和 Bearer token
fastify.interceptors.request.use(config => {
  config.headers = config.headers ?? {};
  config.headers["X-Client-Id"] = getClientId();
  const cookie = Cookies.get("authorized-token");
  if (cookie) {
    try {
      const { accessToken } = JSON.parse(cookie);
      if (accessToken)
        config.headers["Authorization"] = `Bearer ${accessToken}`;
    } catch {
      /* ignore */
    }
  }
  return config;
});

// 响应拦截：解包 + 401 清 token + 双语错误消息处理（优先展示中文）
fastify.interceptors.response.use(
  res => {
    const body = res.data;
    if (body && typeof body === "object") {
      if ("data" in body && Object.keys(body).length === 1) return body.data;
      if ("ok" in body) return body; // admin/db/* 保留完整 { ok, ... }
    }
    return body;
  },
  err => {
    const status = err.response?.status ?? 0;
    // 从后端双语消息 `English | 中文` 中取中文；没有 | 就原样返回
    const raw = err.response?.data?.error ?? err.message;
    const display = (() => {
      if (!raw) return `请求失败 (${status})`;
      const idx = raw.indexOf("|");
      return idx !== -1 ? raw.slice(idx + 1).trim() : raw;
    })();

    if (status === 401) {
      Cookies.remove("authorized-token");
      localStorage.removeItem("user-info");
      window.location.href = "/login";
    }
    return Promise.reject(new Error(display));
  }
);
```

### 13.2 认证流程 — admin 登录自动识别 scope

```ts
// 登录（返回 payload 解包，前端快速判断 scope）
export async function login(username: string, password: string) {
  const res = await fastify.post("/auth/login", { username, password });
  const payload = JSON.parse(atob(res.access_token.split(".")[1]));
  return { ...res, payload };
}

// Vue 组件里用
async function onSubmit() {
  const res = await login(form.username, form.password);
  // scope 判断：决定是不是 admin-panel 用户
  store.isAdminPanel = res.payload.scope === "admin-panel";
  store.objectId = res.payload.object_id;

  // 存 token（注意：后端 expires 是 unix 秒，前端 Cookie 要毫秒）
  Cookies.set(
    "authorized-token",
    JSON.stringify({
      accessToken: res.access_token,
      refreshToken: res.refresh_token,
      expires: res.expires * 1000
    }),
    { expires: (res.expires * 1000 - Date.now()) / 86400000 }
  );
}
```

### 13.6 运维 — 触发后端重启 + 等待恢复

```ts
export async function triggerRestart() {
  // 前置：.env ALLOW_SYSTEM_RESTART=true 且 JWT scope="admin-panel"
  // 后端发完 202 后 1 秒进程退出，PM2 / systemd 拉起新实例
  return fastify.post("/system/restart", {});
  // → { ok: true, message, cooldownSec }
}

// 等后端起来（pm2 拉起需要几秒）
export async function waitUntilBackendRecovered(
  timeoutMs = 30_000
): Promise<boolean> {
  const start = Date.now();
  while (Date.now() - start < timeoutMs) {
    try {
      const res = await fetch("/health");
      if (res.ok) return true;
    } catch {
      /* 后端还没起来，忽略 */
    }
    await new Promise(r => setTimeout(r, 2000));
  }
  return false;
}

// Vue 组件里用
async function onRestart() {
  await triggerRestart();
  ElMessage.success("服务重启中...");
  const ok = await waitUntilBackendRecovered();
  ElMessage(ok ? "服务已恢复" : "重启超时，请手动检查", {
    type: ok ? "success" : "error"
  });
  router.push("/login"); // 刷新 token（旧 refresh 因 family 失效会 401，强制重新登录）
}
```

### 13.7 SQLite WAL 文件状态 — 仪表盘专用

```ts
// /api/admin/db/meta 一次性拿到所有概览数据
export function dbMeta() {
  return fastify.get("/admin/db/meta");
}

// 返回结构（better-sqlite3 pragma 返回数组 ⚠️）：
// {
//   ok: true,
//   journalMode: "wal",
//   tables: 9,
//   rowCounts: { object: 2, users: 5, refresh_tokens: 3, refresh_tokens_expired: 0 },
//   wal: [{ busy: 0, log: 0, checkpointed: 0 }]   // ← 数组！
// }

// WAL 压缩（TRUNCATE checkpoint）
export async function compactWal() {
  const res = await walCheckpoint();
  const [{ busy, log, checkpointed }] = res.result; // 从数组里解构
  if (busy > 0) {
    ElMessage.warning("WAL 正在被其他连接占用，checkpoint 跳过");
  } else {
    ElMessage.success(`checkpoint 完成：${checkpointed}/${log} 帧已合并回主库`);
  }
}
```

### 13.8 关键踩坑速查

| #   | 踩坑点                                                                                  | 正确做法                                                                      |
| --- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 1   | 后端 `expires` 是 **unix 秒**，前端 Cookie 需要 **毫秒**                                | `res.expires * 1000` 转换                                                     |
| 2   | `wal_checkpoint(...)` 返回**数组** `[{busy, log, checkpointed}]`                        | `res.result[0].busy` 或结构 `[{ busy, log, checkpointed }]`                   |
| 3   | 后端字段 **snake_case**（`access_token`），pure-admin 要 **camelCase**（`accessToken`） | `{ accessToken: res.access_token }` 映射                                      |
| 4   | `X-Client-Id` 每次请求必须带（指纹计算 `sha256("cid:" + clientId)`）                    | axios 拦截器里统一注入，不要手动算 hash                                       |
| 5   | refresh 轮换：刷新成功后**必须覆盖本地 refresh_token**（旧的单-use 已作废）             | `localStorage.setItem("refresh_token", res.refresh_token)`                    |
| 6   | `/api/admin/db/delete` / `update` **必须带 WHERE**                                      | 缺 WHERE → 400，后端防误全表操作                                              |
| 7   | admin shadow 用户 id=1，密码不可猜，admin 登录**不走 users 表**                         | 不要在 admin-vue 的用户管理界面看到它就手动删除 —— 会破坏 refresh_tokens 外键 |
